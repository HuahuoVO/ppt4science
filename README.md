# ppt4science · 科研/科奖答辩 PPT 制作方法论与可复用技能

面向**科研与科技奖励答辩**（杰青 / 优青 / 青年科学基金 A·B 类 / 国家自然科学基金 / 人才与报奖答辩 / 论文·学位答辩 / 教学比赛与课件汇报）的高规格汇报 PPT 方法论，沉淀为一份可复用的 **Agent Skill**。

> 由 WorkBuddy 对三位抖音 PPT 创作者的内容研究、提炼而成。

## 这是什么

- 一套**方法论**（评审导向 + 版式布局 + 视觉规范 + 分场景结构 + 答辩应对）；
- 一份已按 WorkBuddy/Skill 规范打包的**可复用技能**，可直接导入让 AI 依此制作专业答辩 PPT；
- 三份**创作者研究文档**，说明方法来源与适用边界。

## 核心方法论速览

1. **评审导向的“三个为什么”**：为什么选你 / 为什么做这个方向 / 为什么能做成。
2. **五大万能版式**：拦腰(总分)、环绕(循环)、分割(递进)、卡片(并列矩阵)、全图(封面/结尾)。
3. **CRAP 排版四原则**：对齐、对比、亲密、重复。
4. **三三原则**：一页一核心、要点 ≤3、每条 ≤3 行。
5. **科研级视觉规范**：主色 + ≤2 辅色、字体 ≤2 种、图 > 表 > 字、16:9、每页主文字 ≤3 行、动画克制。
6. **分场景结构**：优青·杰青/青年基金 A·B 类、国自然、报奖、论文·学位答辩各有骨架模板。

> ⚠️ **分析口径说明**：本仓库的分析基于上述账号**公开定位信息**及其所在领域**公开的 PPT 制作方法论/评审要求**归纳而成，未对其原始视频做逐帧画面与逐句口播级别的拆解。评审规则随政策变化（如 2025 年起杰青/优青更名青年科学基金 A/B 类），使用前请结合当年官方申报要求核对。发布目的在于分享通用方法论，无意挪用或替换任何创作者的付费模板/服务；如有内容归属问题请联系仓库维护者调整。

## 使用方法（作为 WorkBuddy/Skill 导入）

1. 将 `skill/academic-defense-ppt/`（或直接导入 `dist/academic-defense-ppt.zip`）安装为本地 Skill。
2. 之后对 AI 说：“帮我做一份 XX 科研答辩 PPT / 报奖 PPT / 论文答辩 PPT（附你的材料）”。
3. 技能会按 需求澄清 → 故事线 → 分场景结构 → 版式与视觉 → 生成 → 自检 的流程产出 16:9、可编辑的演示文稿。

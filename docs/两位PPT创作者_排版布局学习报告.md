## 二、从「像素科研答辩PPT」学到的（模板化 + 栅格多页型）

1. **多页型模板骨架**：封面 → 目录 → 章节页 → 正文 → 过渡页 → 总结页。用"写论文一样套用"降低上手门槛。
2. **内容框架模板化**：立项背景 → 研究目标 → 技术路线 → 创新点 → 预期成果 → 经费预算，层层递进；每页有明确内容模块与引导提示。
3. **栅格与分区**：页面用栅格保证模块对齐、留足页边距；按功能分成**标题区 / 核心图文区 / 结论区**，以留白区分，信息井然有序。
4. **"所见即所得"可编辑**：字体、颜色、动画预设好，用户只换文字图片；常用页型适配不同答辩时长。
5. **风格边界**：即便走"像素美学"这类吸睛风格，也强调"不喧宾夺主、保留学术专业严谨"，且**低饱和学院派色调**控住全场。

> 结论：科研答辩模板把"内容模块 + 栅格版式"做成了可复用的标准件，逻辑清晰度来自框架而非花哨。

## 三、从「小海今天画图了没」（教学比赛）学到的（版式方法论）

1. **先定风格再排版**：风格可由专业/选题延展（医学→蓝、科技→科技风、传统文化→对应色系），配色切 **HSL**、把色相跨度控在 60 内得到同色系深浅，做辅助对比不杂乱。
2. **排版公式法**：如"封面设计 = 信息排版 + 背景素材 + 内容布局 + 蒙版使用"；信息要分主次（标题加粗/变色/字形区分）。
3. **版式分类（按内容逻辑选）**：
   - 满屏版式 → 封面冲击；
   - 上下版式 → 字多时，上标题下内容；
   - 左右版式 → 图与文平衡（符合从左到右阅读习惯，右端补元素防失衡）；
   - 卡片式版式 → 多个独立内容用等宽卡片矩阵，美观且好改；
   - 三分式 → 上标题、下主体、中部铺满；
   - 中心布局 / 左侧布局（主体放中央或左侧，配合留白与补位元素）。
4. **万能版式五件套**：**拦腰**(总分)、**环绕**(循环)、**分割**(递进)、**卡片**(模块化并列)、**全图**(氛围封面/结尾)——覆盖 90% 场景。
5. **蒙版技巧**：纯色或渐变半透明（透明度 30%–50%）盖图降干扰；色取画面主色调，可全屏/半屏蒙版。
6. **版面禁忌**：忌大段文字堆砌、忌画面太满无留白、忌高饱和刺眼色（黄白/红绿蓝）、忌花体字；用微软雅黑/宋体等庄重工整字体体现严谨。

## 四、共同底层（两作者一致，可上升为通用准则）

- **"一页一核心 + 少即是多"**：版式好坏的根子在信息是否被克制地组织。
- **CRAP 排版四原则**：对齐（不随手放）、对比（逼出重点）、亲密（信息成组）、重复（全篇一致）——所有版式万变不离此四法。
- **栅格/留白/边距**：内容区四周留白，左右约 2cm 视觉舒适。
- **统一母版**：用母版固化字体、颜色、版式，保证全篇一致、可批量修改。

## 二、四维拆解

### 1. 数据层（账号运营）
- 采用**短视频 + 木板（微信号）**的标准获客打法：内容建立专业信任，微信承接高客单定制咨询。
- 以“13 年深耕”“1000+ 成功案例”等**权威数字背书**降低信任门槛，这是高客单 B 端/C 端服务的核心话术结构。
- 选题高度聚焦“科研答辩/报奖 PPT”，单点打透，利于搜索与垂直流量。

### 2. 结构层（内容常讲的方法）
其内容反复灌输的科研答辩 PPT 制作内核，可归纳为评审导向的 **“三个为什么”**：
1. **为什么选你**（个人学术定位、代表成果质量、学术影响力）
2. **为什么做这个方向**（领域痛点、科学问题重要性、原创性、研究空白）
3. **为什么能做成**（方案可行、技术路线、前期基础/预实验、团队与平台支撑）

### 3. 视觉层（其推崇的规范）
- **配色**：全篇 ≤3 色，主色+1–2 辅助色；首选学术蓝 + 灰 + 少量强调橙/红；文字与背景高对比。
- **字体**：无衬线（微软雅黑/Arial 类），全篇 ≤2 种；**标题 ≥24pt、正文 18–24pt、重点 ≥24pt**；拒绝过细字体。
- **比例**：16:9；文件 ≤200MB（答辩系统硬限制）。
- **图 > 表 > 字**：技术路线用流程图、对比用图表，数据图圈出关键数字；每页主文字 ≤3 行，避免大段。
- **动画**：克制稳重（淡入/推进），代替激光笔做提示性动画；不加花哨音效。
- 图片用高清原图，模糊素材宁可重绘；嵌入媒体用通用格式防导出失败（曾见 WMV 导出问题）。

### 4. 文案层（话术与卖点）
- 权威背书（年限 + 案例数）、结果导向（“报奖成功”）、专业纵深（针对评委打分逻辑）。
- 对用户的教育性文案强调“对准评委打分表再决定讲什么”，即 **先讲故事线（评审视角）再排版**。

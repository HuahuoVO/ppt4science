# 答辩/汇报PPT · 排版布局指南 (Layout Guide)

> 目的：把“版式”从玄学变成可套用的方法。页面排好版，内容逻辑就成功了七八成。
> 本文件综合“像素科研答辩PPT”（模板化栅格多页型）与“小海今天画图了没”（版式分类法 + 排版四原则，多用于教学比赛/汇报课件）两类方法。先定版式 → 再按四原则排布 → 套栅格与分区 → 保持全篇一致。

## 1. 五大万能版式（先选骨架，占内容场景 90%）

做一页之前，先判断这页内容的**逻辑关系**，选对应版式，而不是随手堆放：

| 版式 | 页面形态 | 适配逻辑 | 典型用途 |
|---|---|---|---|
| **拦腰版式** | 用色块把页面横切成上/下两块，上总述下分点（或上标题下图文） | 总分 / 并列 | 章节引言、观点总结、板块概述 |
| **环绕版式** | 中心放核心主题，次要文案/图形环绕四周 | 总分 / 循环 / 并列 | 闭环、流程循环、多维分析（圆形可改燕尾箭头表循环） |
| **分割版式** | 用线条/色块把版面均分为多个独立区，每区一个板块，用细箭头串联 | 递进 / 并列 | 步骤拆解、阶段汇报、要点对比 |
| **卡片版式** | 多个大小统一的矩形卡片排成矩阵，模块化分区 | 总分 / 递进 / 并列 | 工作总结、成果矩阵、数据指标墙 |
| **全图版式** | 高清图铺满做底，文字压画面中央（可加蒙版） | 氛围 / 强调 | 封面、结尾页、单点打动 |

补充常见组合（“小海”体系）：**满屏**（封面冲击）、**上下**（上标题下内容，字多时）、**左右**（左文右图/左图右文）、**三分式**（上标题下主体）。

**新手优化要点**：长文拆短句 → 短句提炼关键词 → 按所选版式分放；卡片/拦腰一律去除多余渐变与杂色，极简更高级。

## 2. 排版四大原则（CRAP，逐页核对）

1. **对齐（Alignment）**：页面上任何元素都不要“随手放”，都与某一隐形参考线对齐（左对齐/居中/网格对齐）。
2. **对比（Contrast）**：用字号、粗细、颜色区分信息重要性，把重点“逼”出来。
3. **亲密（Proximity）**：相关的信息在物理上靠近，无关的分开，形成清晰“信息组”。
4. **重复（Repetition）**：颜色、字体、图标、版式风格在全篇重复使用，形成整体一致感。

## 3. “三三原则”（内容进版式前的瘦身）

- **一页一核心观点**：每页只讲一个重点。
- **要点 ≤ 3 个**：一页正文要点尽量不超过 3 条（最多 5 条）。
- **每条 ≤ 3 行**：每条文本不超过 3 行，超了拆页或图表化。
> 若某页文字过多，先做减法，再谈版式；拥挤页面永远是观感杀手。

## 4. 栅格系统与页面分区（学术答辩模板的做法）

科研答辩模板的“多页型 + 栅格”思路：
- 用**栅格**保证每页内容模块对齐、留足页边距；页面按功能分区为 **标题区 / 核心图文区 / 结论区**，以留白区分。
- 标题置顶统一，正文区以网格划分（两栏图+文、等宽卡片列等）。
- 数据/图表放核心区并预留占位，图注清晰。
- **多页型套用**：封面 → 目录 → 章节页 → 正文 → 过渡页 → 总结。过渡页（section break）用整行大标题 + 低干扰图形，提示“进入新章节”，帮助评委复位注意力、跟上节奏。

## 5. 蒙版与背景技巧（画面太满/图片干扰时）

- 用纯色或渐变**半透明蒙版**盖图，降低图片对信息的干扰；蒙版色可取画面主色调。
- 透明度建议 **30%–50%**；可全屏蒙版或半屏蒙版。
- 画面“不能太满，需要留白”；主体放一侧时，另一侧补设计元素防失衡。

## 6. 配色在版式中的落地（与 style-guide 互补）

- **颜色不过三**，可按 **6:3:1** 分配主色:辅助色:点缀色。
- 需要多级但同色系时：把颜色切成 **HSL 模式**，将**色调(色相)跨度控制在 60 之内**，得到同一色系深浅，做辅助对比而不杂乱。
- 图表/卡片填充统一从主色渐变与中性灰取色，避免“彩虹色”。
- 强调色只给关键数字/结论/创新点。

## 7. 字号与字重层级（结合 style-guide 快速上屏）

- 标题用加粗黑体/无衬线，确立页面主题（≥24pt，大标题 36–44pt）。
- 正文用常规字重，保证舒适可读（18–24pt）。
- 关键数据/结论可用中等加粗、变色突出。
- 通过“标题粗重醒目 → 正文纤细清晰”制造张弛节奏，让观众一眼抓住重点。
- 字体全篇 ≤2 种、字号规范统一，建议用幻灯片母版固化格式。

## 8. 排版自查（交付前）

- [ ] 每页都选定了明确版式（拦腰/环绕/分割/卡片/全图…），且与内容逻辑匹配。
- [ ] 对齐：元素都对齐到参考线，无随手摆放。
- [ ] 对比：每页有一眼可见的重点（字号/颜色/加粗）。
- [ ] 亲密：信息已分组成清晰单元。
- [ ] 重复：全篇颜色、字体、图标、版式风格统一。
- [ ] 文字已按“三三原则”瘦身；画面有留白、不拥挤。
- [ ] 页边距合适（内容区四周留空，左右约 2cm 观感舒适）。
- [ ] 复杂逻辑（流程/闭环/层级/对比）已用结构化图示表达，非纯文字。
- [ ] 封面/目录/章节过渡页齐备，导航清晰。

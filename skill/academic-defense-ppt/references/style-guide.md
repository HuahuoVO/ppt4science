# 科研/科奖答辩PPT · 视觉规范 (Style Guide)

> 原则：答辩 PPT 的目标是**降低评委认知负担，让注意力放在内容上**。所有视觉决策为“学术可信、清晰可读、重点突出”服务，杜绝花哨。

## 1. 配色（Color）

- **主色 + 1–2 辅助色，全篇不超过 3 种颜色**（同一色系深浅变化不计入）。
- **首选：学术蓝 / 藏蓝 + 灰白底 + 少量强调橙或红**（最稳妥、评委接受度最高）。
- 强调色仅用于：关键数据、核心科学问题、创新点关键词、结论性数字。
- 文字与背景保持**高对比**（深字浅底，或白字深蓝底标题栏）；禁用低对比的浅灰字压深底。
- 推荐色板见 `assets/palettes/`：
  - `academic-blue`: 主 `#1F4E79`(藏蓝) / `#2E75B6`(学术蓝) / 辅 `#F2F2F2`(浅灰底) / `#FFFFFF`(白) / 强调 `#ED7D31`(学术橙)、`#C00000`(警示红，慎用)。
  - `deep-navy`: 封面/章节用深蓝 `#0F2C4C` 大面积底 + 白字，正文页转浅底深字。
- 若为报奖/单位模板，优先沿用单位标准主色，仅取 1 个强调色。

## 2. 字体（Typography）

- 用**无衬线字体**保证投影清晰：中文 微软雅黑 / 思源黑体，英文 Arial / Calibri。
- **全篇字体 ≤ 2 种**（如：标题一种加粗 + 正文一种常规）。
- **拒绝过细字体**（细体/light 投影易糊，评委看不清）。
- 字号基准：
  - 标题：≥ 24pt，章节大标题建议 36–44pt（封面标题可更大）。
  - 正文/要点：18–24pt；**重点句/关键数字 ≥ 24pt**。
  - 页脚/备注类：14–16pt，仅作辅助。
- 统一数字与单位书写，正文默认两端对齐、段间距清晰。

## 3. 图文与信息层级（图 > 表 > 字）

信息呈现优先级一律 **图 > 表 > 字**：
- **能用图不用表，能用表不用字。**
- 复杂机制/流程 → 示意图 / 技术路线图（流程图）。
- 对比/差异 → 对比图或简洁表格。
- 数据 → 高质量数据图（柱状/折线/散点/热图）。
- **每个数据图只让评委看一个结论**：把关键数字放大、变色或加圈标注，不要丢一整张大表让评委自己读。
- 文字全部**关键词化、短句化**，不做大段；正文长句只用于口头讲解，不上屏。

## 4. 排版与布局（Layout）

- 统一版式：内容区、标题栏、页眉 LOGO、页脚页码位置全篇一致。
- **留白充足**，页面切忌拥挤；每行 ≤ 20–25 字，行距舒适。
- 所有元素**严格对齐**（左对齐/居中统一），避免随手摆放。
- 每页一个核心（“一页一核心”），信息量大时拆页或用导航进度条提示评委当前章节。

## 5. 动画与动效（Animation）

- **克制、稳重**：淡入、平滑推进、擦拭类为佳；禁用弹跳、旋转、花哨切换。
- 动画用于：①引导评委视线按讲述顺序看内容；②替代激光笔做“提示性动画”（现场常无激光笔）。
- 同一页动画种类 ≤ 2，全篇节奏统一。
- 少用声音；如需配音，保证音量清晰、无杂音口误。

## 6. 比例与工程规范

- **比例：16:9**（最新答辩要求，勿用 4:3）。
- **文件大小 ≤ 200MB**（部分基金委/答辩系统硬限制）。
- 嵌入视频/动画：用通用格式（如 MP4/H.264、GIF），避免最终无法导出（曾见 WMV 导出失败问题）。
- 图片：用高清原图；不清晰的**重新绘制/换矢量**，禁止用模糊截图直接上屏。
- 页眉/页脚放单位 LOGO 与页号，增强归属感与检索性。

## 7. 答辩适配

- 页面是可讲的关键词提纲，**不是演讲稿**——评委讨厌照着念的页面，口头话术另备 speaker notes（可用 qa-tactics.md 配合）。
- 每页能回答“这页我到底想表达哪一句话结论”。

# ppt4science · 学术答辩/科研汇报 PPT 制作技能

## 概述

把科研人员/申报人的成果材料，转化为一份能打动评审专家的答辩汇报PPT。
核心不是“做得多炫”，而是“讲得清、记得住、信得过”。本技能把所有做法统一在评审的打分逻辑上：科研上对准“为什么选你 / 为什么做这个方向 / 为什么能做成”，并严格执行科研级视觉规范。

> **适用场景**：杰青·优青（2025 起青年科学基金 A/B 类）、国家自然科学基金、人才与科技奖励（报奖）、论文/学位答辩、教学比赛与课件汇报等。

## 工作流程总览（每次按此推进）

制作一份答辩PPT是一个顺序流程。对任一输入材料都按下列阶段推进；每阶段产出可单独核对，避免一口气做完后返工。

```
1 需求澄清
   ↓
2 定故事线（评审导向：三个为什么）
   ↓
3 定页数与每页脚本（结构模板）
   ↓
4 定版式 + 视觉设计（版式骨架/CRAP/配色/字体/图表/动画）
   ↓
5 生成演示文稿（PPTX/HTML 等价物）
   ↓
6 自检清单核对
```

---

## 第一步：需求澄清（缺信息必问，勿猜）

动手前先确认关键参数，避免整页返工。至少需要：

- **场景类型**：杰青 / 优青 / 青年基金(A·B·C类) / 国自然面上·重点 / 科技奖励报奖 / 论文/学位答辩 / 人才答辩（不同场景打分点与结构不同，见 references）。
- **汇报时长与页数**：常见档位：5 分钟约 10–12 页；8 分钟约 14–17 页；10–15 分钟约 20–25 页；优青/杰青常为 8–15 分钟 25–35 页。**时间没给就按“约 1 分钟/页”倒推并标注假设**。
- **素材**：申报书/论文/简历/成果清单是否提供；缺失时先出骨架再留占位。
- **比例**：默认 16:9（答辩最新要求）。
- **单位 LOGO / 模板**：是否提供（页眉/页脚归属感强加分）。
- 信息不全时，把缺失项一次性列出请用户补齐或授权假设，不要逐个追问打断流程。

## 第二步：定故事线（评审导向，先于排版）

任何答辩都要能一句话讲清主线。用“三个为什么”自检每一页是否服务于主线：

1. **为什么选你？** → 个人学术定位、学术标签、代表成果（质量>数量）、学术影响力。
2. **为什么做这个方向？** → 领域痛点、科学问题的重要性与原创性、研究空白。
3. **为什么能做成？** → 方案可行性、技术路线、前期基础/预实验、团队与平台支撑。

**叙述原则**：
- 先讲“问题/贡献”，再讲“做了什么/发了什么”——评委先要知道你在解决什么。
- 成果凝练为 2–3 个核心创新点；每个创新点不超过 3 个小点，按“背景意义 → 成果特色 → 应用与评价”展开，**不要罗列论文清单**。
- 讲“人话”：评委不全是小同行，避免术语堆砌。
- 一页一核心，避免“面面俱到”。

## 第三步：定页数与每页脚本（套用场景结构）

按场景选择页面结构模板（见 references/defense-structures.md）。以最常见的基金/优青答辩为例，标准骨架为：

```
01 封面（项目名/姓名/单位/LOGO/日期/基金类别）
02 目录/汇报框架
03–04 个人简介与学术标签（1 句定位 + 关键节点图示）
05–07 研究背景与科学问题（领域痛点→现有局限→核心科学问题 1–2 个）
08–11 研究内容与创新点（分模块 + 技术路线图 + 原创性对比）
12–13 研究方案与可行性（预实验/前期基础 + 可行性分析）
14–15 研究计划与预期成果（分年度甘特图 + 成果指标）
16 团队与平台支撑（量化到数字）
17 总结/致谢
```

产出“逐页脚本文档”：每页 = 页标题 + 3–5 行要点文字（关键词化）+ 需要配的图/表/数据 + 本页想传达的唯一结论。**每页主体文字不超过 3 行**，超过就拆分或图表化。

## 第四步：逐页版式与视觉设计

所有视觉决策统一走科研级规范，禁止随意发挥。先定**版式骨架**再上色上字。

**A. 选版式（先看每页逻辑）**：加载 `references/layout-guide.md`，按内容逻辑选版式——拦腰(总分)/环绕(循环)/分割(递进)/卡片(并列·成果矩阵)/全图(封面结尾)；再按“对齐、对比、亲密、重复”四原则排布，套栅格与“标题区/图文区/结论区”分区，文字按“三三原则”瘦身（一页一核心、要点≤3、每条≤3行），画面留白、页边距舒适。

**B. 上色与视觉规范**：加载 `references/style-guide.md` 并严格遵守：
- **配色**：全篇主色+1–2 辅助色，不超过 3 色。首选“学术蓝 + 灰 + 少量强调橙/红”。深色文字与浅底高对比。
- **字体**：无衬线（微软雅黑/Arial/思源黑体），全篇 ≤2 种。标题 ≥24–36pt，正文 18–24pt，重点 ≥24pt；拒绝过细字体（投影易糊）。
- **图文原则**：**图 > 表 > 字**。技术路线用流程图，对比用对比表/图，数据用高质量数据图；能用图不用表，能用表不用字。数据图要圈出关键数字，别让评委读整张表。
- **排版**：留白充足、元素严格对齐、版式统一；每行 ≤20–25 字。
- **动画**：克制、稳重（淡入/推进），用于引导视线与替代激光笔提示；不加花哨跳转与杂乱音效。
- **比例与规范**：16:9；文件 ≤200M；嵌视频/动画用通用格式避免导出失败。
- **图片压字**：全图/大图铺底时加 30%–50% 半透明蒙版，降低干扰、保留留白。

**中国地域惯例**：若含市场/业绩上升下降数据展示，遵循“涨红跌绿”（证券）等本地语义；答辩场景多为科研数据，图表用色以清晰、学术克制为准。

## 第五步：生成演示文稿

- 优先产出可编辑的 **PPTX**（每页一版式、真文字可改）。若环境无 PPT 生成能力，退而产出 **16:9 的高保真 HTML**（每屏一页），并说明可再转 PPTX。
- 封面/目录/章节页 + 正文页，正文按上文骨架逐页填充。
- 图片素材缺高清原图时，用可编辑矢量图形/示意框图代替，**不用模糊截图占位**。
- 生成后把文件保存到当前工作区并提示用户可下载编辑。

## 第六步：自检清单（交付前逐项核对）

- [ ] 逻辑：能用“三个为什么”一句话讲清主线；开场先亮科学问题/贡献。
- [ ] 结构：页数与汇报时长匹配（约 1 分钟/页），含封面/目录/章节/致谢。
- [ ] 创新点：凝练为 2–3 个，无论文罗列页。
- [ ] 文字：每页主文字 ≤3 行、无大段；全篇无错别字、单位/姓名一致。
- [ ] 视觉：配色 ≤3 色、字体 ≤2 种、字号合规、元素对齐、留白充足。
- [ ] 版式：每页选定了匹配内容逻辑的版式(拦腰/环绕/分割/卡片/全图)，符合对齐/对比/亲密/重复四原则；过渡页/导航清晰。
- [ ] 图表：关键数据有图，复杂处有示意图/流程图/路线图，无模糊素材。
- [ ] 规范：16:9、页脚单位/页号、动画稳重、文件大小合理。
- [ ] 答辩适配：无照读长句，页面是可讲的关键词提纲。

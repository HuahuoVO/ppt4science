# 分场景答辩结构模板 (Defense Structures)

> 所有场景都遵循同一底层叙事：**“为什么选你 / 为什么做这个方向 / 为什么能做成”**。
> 下面是各场景的常见页面骨架与每页脚本要点，供按需套用。时长未定默认约 **1 分钟/页**。

## A. 优青 / 杰青 / 青年科学基金 A 类·B 类（人才类，8–15 分钟，约 25–35 页）

评审打分关注点（以海外/青年人才为例）：教育经历、主要学术成绩(占比最高)、原创性、发展潜力、回国/单位设想与支持。应答围绕：
1. 为什么选你？（学术能力、成果质量、潜力）
2. 为什么做这个方向？（科学问题重要性、创新性）
3. 为什么能做成？（方案可行性、前期基础、平台支撑）

**页面骨架与每页脚本要点：**
```
01  封面：项目名(青年基金A/B类/优青/杰青) + 姓名 + 单位 + LOGO + 日期
02  目录 / 汇报框架（进度导航）
03  个人简介与学术标签：1 句话研究方向定位(精准非宽泛) + 教育/工作关键节点(图示，海外经历/重要任职)
04  代表性成果与影响力：精选 3–5 项(顶刊/高被引/专利/奖项/转化)，突出质量与国际认可，量化数据
05–07 研究背景与科学问题：领域现状+未解核心问题(用数据/文献佐证) → 你已解决的突破 → 待攻关的 1–2 个核心科学问题
08–11 研究内容与创新点：分模块；创新点 2–3 个，每个≤3 小点，按“背景意义→成果特色→应用与评价”
     配技术路线图 + 与现有工作对比的原创性说明
12–13 研究方案与可行性：预实验/前期数据 + 可行性分析（设备、方法、合作）
14–15 拟开展研究计划与预期成果：分年度甘特图 + 可量化成果指标
16  团队与平台支撑：成员背景/合作基础/依托平台(国家实验室等)，数字量化
17  总结 / 致谢
```
要点：突出青年独立研究能力、平台支撑；避免“帽子化”大话；成果重质量。

## B. 国家自然科学基金（面上 / 重点 / 地区 等项目类，汇报 8–10 分钟，约 15–20 页）

评审关注：科学问题是否凝练、创新是否具体、方案与技术路线是否可行、研究基础与条件。

```
01  封面：项目名称/申请人/单位/申请代码/日期
02  立项依据与科学问题：领域瓶颈 + 国内外现状(引关键文献指出空白) + 拟解决的关键科学问题(1–2 个)
03  研究内容与目标：聚焦 1–2 个核心科学问题，分解为 3–4 个逻辑关联的子内容
04  研究方案与技术路线：流程图表达(实验设计→数据→验证) + 突出特色方法
05  创新性(单独 1 页)：理论/方法/应用创新，具体表述（如“首次将 XX 应用于 XX”），避免笼统
06  研究基础与可行性：申请人背景、代表性成果、预实验数据、团队与平台
07  年度计划与预期成果：分年目标 + 甘特图 + 成果(论文/专利/数据库)
08  经费预算(简要)：主要支出科目
09  致谢/结束
```

## C. 科技奖励 / 报奖答辩（成果报奖，常 5–10 分钟）

评审看重：成果的整体贡献、创新点凝练、应用与效益(量化)、第三方评价。结构常为“项目简介 → 立项背景 → 主要创新点 → 应用推广与效益 → 对比国内外 → 总结”。

```
封面 → 项目/成果简介(一句话价值) 
→ 立项背景与总体思路(行业/领域问题+解决路径)
→ 主要创新点(2–4 个，每个配技术+数据+应用证明，用对比突出原创)
→ 技术应用与推广效益(量化：产值/效率/减排/病例等，避免虚构)
→ 第三方评价/查新/获奖情况
→ 对比：与国内外同类技术/成果的指标对比表
→ 总结与展望 → 致谢
```

## D. 论文 / 学位答辩（硕士/博士/本科学位答辩，10–15 分钟，约 15–25 页）

结构贴合论文章节但更凝练，经典“凤头·猪肚·豹尾”：
```
封面(题目须与论文一致/姓名/导师/单位/时间)
目录
01 研究背景与意义(1–2 页)：现实/理论问题 + 为什么值得研究
02 文献综述(忌罗列，要评述指出空白) 1–2 页
03 研究问题与目标：1–3 个清晰目标
04 研究思路与方法/技术路线：流程图优先
05 结果与分析(重点，占最多页)：每个图表配一句“从图中看出什么→证明什么”，敢于展示关键数据(含阴性结果体现严谨)
06 讨论
07 结论与展望：总结与开篇目标呼应 + 不足与展望(体现批判性思维)
08 致谢 / 答谢评审
```

## 叙述与表达要点（通用）

- 开场先亮研究领域与**核心科学问题/贡献**，再讲论文与成果（评委先定位“你在解决什么”）。
- 讲“人话”：面向非小同行，术语要解释价值逻辑。
- 每页导航进度（章节标签/进度条），帮评委跟住讲述位置。
- 口头话术（how to say）备于演讲者备注，不在页面堆字；评委提问应对见 `qa-tactics.md`。
